    Import car classes

    Format

    CSV columns: id, name, aliases, category, era, dlc, description, image_path, active. Only name is required. Separate aliases with semicolons. Rows without an ID are matched by name or alias.

    Import tracks

    CSV columns: layout_id, layout_name, short_name, location_id, location_name, aliases, era, dlc, image_path, active, random_eligible. layout_name and location_name are required. New location names create new locations. Tip: export first, edit the file, then import it.

    Export

    Exports include archived entries. Cells that a spreadsheet could treat as formulas are made safe.

    Championship track names

    Finds track names saved in championships that the catalogue doesn't recognise. Their images fall back to a placeholder. Fix one by adding the saved name as an alias of the right layout.
